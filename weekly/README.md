# weekly/

Hero images for the Aspen Dream weekly promo email, served via GitHub Pages.

Convention: each week's agent uploads the hero image here as
`weekly/YYYY-MM-DD.png` (or `.jpg`) on the `main` branch, then uses the
public URL in the email HTML:

    https://javoom.github.io/aspen-email-assets/weekly/YYYY-MM-DD.png

Pages rebuilds from `main` within about a minute of the commit.
